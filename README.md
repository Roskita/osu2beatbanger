# Beat Banger Mania

Convert 4K osu!mania .osz to and from Beat Banger Release mods.

# Better [Webpage](https://roskita.github.io/beat-banger-mania/) Version

The converter accepts valid Beat Banger mods that have been zipped. converted .zip files should be extracted directly to your mods folder. 

## [How to use the Python Package version for the rest of you nerds](https://github.com/Roskita/beat-banger-mania/docs/building.md)

<u>NOTE:</u> Despite the importance of animations, Beat banger uses keyframe loops and I don't feel like figuring out how to convert that to a singular video file suitable for mania, so that don't work

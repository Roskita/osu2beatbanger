# static [webpage](https://roskita.github.io/beat-banger-mania/) version :3 
The converter takes in a valid Beat Banger mod as a zip, and converted mods should be directly extracted to your mods directory. <br><br>
<u><strong>NOTE: </strong></u> While videos do get converted, Beat Banger animations use key frame loops, and I don't feel like parsing them into a singular video file.

How the formats line up

osu!mania (.osz)

Hit objects
Each note's x-position (0–512) maps to one of 4 lanes; long notes carry an end time.
Timing point
The first uninherited timing point sets the BPM used by the whole chart.
Metadata
Title / Artist / Creator / Version become the mod's song title, song artist, author, and chart name.
Events
The declared background image is carried across as the mod's background.
⇄

Beat Banger mod

notes.cfg
Notes as { input_type, timestamp } pairs, one chart per osu! difficulty found.
keyframes.cfg
Holds the BPM modifier and the background reference for the level.
mod.cfg / act.cfg
Song title, artist, and author, plus a fresh act/level ID.
Audio & images
Song file copied as-is; icons and preview art are generated placeholders.

Before you trust the output

  • Only 4-key osu!mania charts are supported — 5K/6K/7K maps are skipped.
  • Charts with a BPM change mid-song aren't supported; the target format has no equivalent field, so converting anyway would silently desync notes.
  • Long-note (hold) timing is carried over, but the on-disk format for holds hasn't been confirmed against a real Beat Banger example — double-check them in-game.
  • Icons, splash art, and waveform thumbnails are generated as plain placeholders, since osu! charts don't carry equivalents for those.

Runs entirely in your browser — files are read, converted, and zipped locally; nothing is uploaded anywhere.
